# Microsoft's Pragmatic Rust Guidelines, by area

The house rules in `SKILL.md` build on Microsoft's [Pragmatic Rust Guidelines](https://microsoft.github.io/rust-guidelines/) (MIT). Each guideline has a stable ID such as `M-PANIC-ON-BUG`. The links below open each one at commit `19723b3` of [microsoft/rust-guidelines](https://github.com/microsoft/rust-guidelines), the version the house rules were checked against.

Open only the guidelines for the area you're working in. To read all 90 in one file, fetch [agents/all.txt](https://microsoft.github.io/rust-guidelines/agents/all.txt), the book's single-file form for agents. That file follows the latest book rather than this commit.

## Updating the pin

1. Find the latest commit on `main` of microsoft/rust-guidelines.
2. Read what changed since `19723b3`, and check each house rule that cites a changed or new ID.
3. Replace the commit in every link, and list any new ID under its area.
